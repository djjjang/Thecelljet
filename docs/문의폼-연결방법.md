# 더셀젯 상담 신청서 → 시트 · 메일 · 카톡 연결 방법

신청이 들어오면 ① 구글 시트에 쌓이고 ② 메일로 알림이 오고 ③ (설정하면) 카카오톡 알림톡으로도 알림이 옵니다.
**어느 구글 계정으로 만들지 먼저 정하세요.** 신청 고객 정보가 그 계정 시트에 쌓입니다. 고객사 정보이므로 이수미 대표님 계정을 권장합니다.

## 1단계: 시트 + 메일 (약 10분, 오늘 바로 가능)
1. https://sheets.new 에서 새 시트를 만들고 제목을 `더셀젯 상담신청`으로 바꿉니다.
2. **확장 프로그램 → Apps Script**를 엽니다. 기존 코드를 지우고 `google-apps-script.js` 내용을 통째로 붙여 넣습니다.
3. 맨 위 `NOTIFY_EMAILS`에 알림 받을 메일 주소를 넣습니다. 예: `'sumi@naver.com,djjjang1@naver.com'`
4. 저장한 뒤 **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 권한 허용 창이 나오면 허용합니다. "확인되지 않은 앱" 경고가 나오면 **고급 → 이동**을 누르세요. 직접 만든 스크립트라서 나오는 경고입니다.
6. 마지막에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 자비스에게 붙여 주세요. `src/data/site.js`의 `formEndpoint`에 넣고 시험 신청을 보내 확인합니다.

> 웹 앱 URL은 비밀번호가 아니라서 대화창에 붙여도 괜찮습니다. 구글 비밀번호는 절대 붙이지 마세요.

## 2단계: 카카오 알림톡 (준비 3~7일, 소액 유료)
카톡 알림은 무료 방법이 없습니다. 아래 순서로 준비합니다.

1. **카카오톡 채널 만들기**: https://center-pf.kakao.com 에서 "더셀젯" 채널을 만들고 **비즈니스 인증**을 받습니다. (사업자등록증 필요, 1~3일)
2. **솔라피(SOLAPI) 가입**: https://solapi.com — 문자·알림톡 발송 대행 서비스입니다. 충전식이며 알림톡 1건 약 10원대입니다. (정확한 단가는 가입 화면에서 확인)
3. 솔라피에서 **발신번호 등록**(010-7781-6533 등)과 **카카오 채널 연동**을 합니다. 연동하면 `pfId`가 나옵니다.
4. 솔라피에서 **알림톡 템플릿 등록** → 카카오 검수(1~3일). 템플릿 내용은 아래를 **그대로** 쓰세요.

```
[더셀젯] 홈페이지 상담 신청이 접수되었습니다.

샵: #{샵}
성함: #{성함}
연락처: #{연락처}
업종: #{업종}
문의: #{문의}
```

5. 승인되면 **Apps Script → 프로젝트 설정(톱니바퀴) → 스크립트 속성**에 아래 6개를 추가합니다. (API 키는 코드에 직접 적지 않습니다)

| 속성 | 값 |
|---|---|
| SOLAPI_API_KEY | 솔라피 API Key |
| SOLAPI_API_SECRET | 솔라피 API Secret |
| SOLAPI_PF_ID | 카카오 채널 연동 후 받은 pfId |
| SOLAPI_TEMPLATE_ID | 승인된 템플릿 ID |
| SOLAPI_FROM | 솔라피에 등록한 발신번호 |
| KAKAO_TO | 알림 받을 휴대폰 번호 (여러 개면 쉼표) |

6. 편집기에서 `testNotify` 함수를 골라 **실행** → 메일과 카톡이 오는지 확인합니다.
7. 코드를 고쳤다면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (주소 유지).

> 알림톡이 실패하면 같은 내용이 문자(LMS)로 대신 갑니다. 카톡 준비가 늦어지면 템플릿 없이 문자만 먼저 쓰는 것도 가능합니다.

## 참고
- 「소식 수신 동의」가 **Y**인 분에게만 홍보 문자·메일을 보낼 수 있습니다.
- 상담 종료 후 1년이 지난 신청 정보는 삭제해야 합니다 (개인정보처리방침에 그렇게 적혀 있음).
