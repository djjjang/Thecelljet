새 직원이 장비 앞에서 가장 먼저 막히는 곳은 **화면**입니다. 버튼이 많아 보여도, 순서대로 보면 단순합니다. 더셀젯 본체 화면을 구역별로 정리했습니다.

## 켜는 순서

1. 기기 뒤쪽에 전원선과 핸드피스 케이블이 연결됐는지 확인합니다
2. 앞쪽 아래 버튼을 눌러 전원을 켭니다
3. **비밀번호(PIN)**를 입력하면 작동 화면으로 바뀝니다

## 화면 구역 한눈에

| 구역 | 하는 일 |
|---|---|
| 관리 부위 (TREATMENT AREA) | 스페셜 · 두피 · 얼굴&목 · 바디 4가지 모드 선택 |
| 샷 속도 (SHOT/SECOND) | 1초에 몇 번 분사할지 (최대 5회, 바디는 1회 단발) |
| 강도 (INTENSITY) | 1~9단계 강도 조절 |
| 메모리 1~5 · 저장 | 자주 쓰는 설정 5개 저장 · 불러오기 |
| 샷 카운트 (SHOT COUNT) | 분사한 횟수 표시 |
| 시작 (START) | 설정을 마치고 시작 |

## 1. 모드부터 고르세요

관리할 부위에 맞춰 **모드를 먼저** 고릅니다. 모드마다 부위별 강도 기준이 있어서, 모드를 잘못 고르면 강도 기준도 어긋납니다.

## 2. 강도와 샷 속도

강도는 **1~9단계**입니다. 처음 사용할 때는 낮은 단계부터 시작하세요. 본체에서 정한 강도는 핸드피스 레벨바에도 그대로 표시됩니다.

샷 속도는 1초에 몇 번 분사할지 정하는 값입니다. 처음에는 느리게, 손에 익으면 조금씩 올리세요.

## 3. 메모리 5개를 샵 기준으로

자주 쓰는 설정은 **저장 버튼**으로 메모리 1~5번에 넣어 두세요. 예를 들어 1번 눈가, 2번 턱라인, 3번 두피처럼 번호를 정해 두면 누가 관리해도 같은 설정으로 시작할 수 있습니다.

## 4. 기록과 점검 화면

더셀젯은 **사용 기록(로그)**을 남기고, **압력을 점검하는 화면**도 있습니다. 관리가 끝나면 샷 카운트와 설정을 고객 기록에 옮겨 적어 두세요.

---

## PIN 잠금은 꼭 쓰세요

장비를 켤 때 **비밀번호를 입력**해야 하므로, 교육받지 않은 사람이 장비를 켜는 일을 막을 수 있습니다. 더셀젯은 교육받은 사람이 사용하도록 만들어진 전문가용 장비입니다. 비밀번호는 교육을 마친 직원에게만 알려 주세요.

## 화면 체크리스트

- [ ] PIN을 입력하고 켰다
- [ ] 관리 부위에 맞는 모드를 골랐다
- [ ] 강도는 낮은 단계부터 시작했다
- [ ] 메모리 번호별 설정을 직원 모두 안다
- [ ] 끝나면 샷 카운트를 기록했다

더셀젯은 도입 교육에서 화면 설정부터 메모리 저장까지 직접 보여 드립니다.
