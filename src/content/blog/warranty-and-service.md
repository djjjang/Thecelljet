장비는 한 번 들이면 몇 년을 함께 씁니다. 그래서 장비 가격만큼 중요한 것이 **고장 났을 때 어떻게 되는지**입니다. 계약할 때는 잘 안 묻다가, 막상 장비가 멈추고 나서야 보증 조건을 찾아보는 경우가 많습니다.

더셀젯 품질보증 기준으로 미리 알아 둘 것을 정리했습니다.

## 무상 보증: 구입일부터 1년

보증 기간 안에 **정상적으로 사용하다가** 제품 자체의 성능이나 기능에 문제가 생기면 무상으로 수리받을 수 있습니다. 보증 기간이 지나면 유상 수리가 원칙입니다.

👉 구입일을 증명할 수 있도록 **품질보증서와 구입 서류**를 한곳에 보관해 두세요.

## 보증 기간 안이라도 유상인 경우

| 경우 | 예시 |
|---|---|
| 잘못 쓰거나 부주의로 생긴 고장 | 사용설명서와 다르게 사용 |
| 임의로 분해·개조하거나 공인되지 않은 곳에서 수리 | 직접 열어 보거나 다른 곳에 수리를 맡김 |
| 떨어뜨림, 충격, 물에 젖음 | 핸드피스를 바닥에 떨어뜨림 |
| 화재, 낙뢰, 수해 같은 천재지변 | 침수 피해 |
| 소모품의 정상적인 마모와 교체 | 실린더 같은 소모품 |

이 표를 직원들과 함께 보세요. 특히 **핸드피스를 떨어뜨리지 않게 거치대에 두는 습관**만으로도 수리비가 드는 일을 크게 줄일 수 있습니다.

## A/S 신청할 때 준비할 것

장비에 이상이 생기면 먼저 **사용을 멈추고** 고객센터에 연락합니다. 이때 아래 네 가지를 알려 주면 접수가 빨라집니다.

1. 제품명
2. 구입 날짜
3. 시리얼번호(S/N): 품질보증서와 본체에서 확인
4. 고장 증상: 언제부터, 어떤 상황에서, 어떻게

수리할지 교체할지는 제품을 점검한 뒤 안내받습니다.

👉 증상을 **사진이나 짧은 영상**으로 남겨 두면 설명하기 훨씬 쉽습니다.

## 계약 전에 물어볼 것

- 무상 보증 기간과 시작일(구입일 기준인지)
- 수리하는 동안 예약을 어떻게 할지 (대체 장비가 있는지)
- 소모품을 어디서, 얼마에 살 수 있는지
- 도입 교육은 몇 번, 새 직원도 받을 수 있는지

## 보증·A/S 체크리스트

- [ ] 품질보증서와 구입 서류를 보관했다
- [ ] 시리얼번호 위치를 알고 있다
- [ ] 유상 수리 경우를 직원들과 공유했다
- [ ] 핸드피스 거치 습관을 정했다
- [ ] 고객센터 연락처를 장비 옆에 붙여 두었다

더셀젯은 상담할 때 보증 조건과 A/S 절차를 함께 안내해 드립니다.
